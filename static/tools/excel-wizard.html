Ready formula to paste:
=XLOOKUP(A2, Table2[ID], Table2[Name], "Not found", 0)
🔍 Step-by-Step Argument Breakdown:
  • A2 — lookup value (item code or name).
  • Table2[ID] — lookup array to search in.
  • Table2[Name] — return array with desired output.
⚠️ Common Pitfalls to Avoid:
  • In non-English locales, argument separators may be semicolons (;) rather than commas (,).
  • Lookup and return ranges must have identical dimensions.
